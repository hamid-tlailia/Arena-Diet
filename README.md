# لومينا دايت · Lumina Diet

رفيقك الذكي للرشاقة — تطبيق React يجمع **أنجع 4 أنظمة دايت** في مكان واحد مع مدرّب تحفيزي ذكي.

> Your smart companion for the 4 most effective diets — with an AI-style motivational coach.

## ✨ المميزات

- 🕐 **الصيام المتقطع** — 6 بروتوكولات (12:12 حتى OMAD) مع مؤقّت حيّ، حلقة مضيئة، وإيقاف/بدء دائم (يستمر حتى بعد إغلاق التطبيق)
- 🧬 **رحلة الجسم أثناء الصيام** — 8 مراحل فسيولوجية (هضم ← كيتوزية ← التهام ذاتي ← تجديد عميق)، شعار كل مرحلة يشتعل حسب الساعات المنقضية، وشرح كامل بالضغط عليها
- 🥗 **4 أنظمة موثقة** — صيام متقطع، كيتو، بحر متوسط، لو-كارب: الطريقة، المميزات، المسموح ✅ والممنوع ⛔، التمارين المناسبة، نصائح وحقائق
- 🤖 **مدرّب ذكي** — إشعارات تحفيزية مولّدة محليًا حسب نظامك ومرحلة صيامك وسلسلتك، بصيرة يومية، رادار شغف يتتبع اهتماماتك ويقترح الأنسب
- 🌗 **ثيمات تحفيزية متكيفة** — «وضع الشروق» نهارًا و«وضع السكينة» ليلًا (تلقائي أو يدوي)، زجاجية وأورورا متحركة
- 🌍 **عربي ⇄ English** — مع دعم RTL/LTR كامل
- 🏆 **أوسمة وسلاسل التزام** — gamification يشجّع على الاستمرار
- 💾 **بدون قاعدة بيانات** — Zustand persistent store (localStorage)

## 🛠 التقنيات

React 18 · Vite 5 · Tailwind CSS 3 · Zustand (persist) · Framer Motion · Lucide Icons

npm run dev      # تطوير
